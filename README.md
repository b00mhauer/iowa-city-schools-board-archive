# Iowa City Schools Board Archive

**Status: the public site is currently taken down.** It shows an
"under construction" landing page while the archive's content is
reworked.

https://b00mhauer.github.io/iowa-city-schools-board-archive/

## Where the originals live

Primary source PDFs and meeting videos stay on the district's
[Simbli eBoardSolutions site](https://simbli.eboardsolutions.com/). This
repo links to them rather than mirroring them.

## Repo layout

- **`docs/`** — the published site. Currently a single
  under-construction landing page.
- **`scripts/`** — generator tooling that walks the district's eBoard
  API, scrapes attachment IDs, and builds meeting pages, transcripts,
  and extracts. The content it previously generated has been removed
  from the repo.

The site is generated by
[MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and
deployed automatically by GitHub Actions on every push to `main`.
